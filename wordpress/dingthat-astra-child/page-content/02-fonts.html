Ding That is a set of three fonts with 267 glyphs between them. Each glyph sits on a keyboard key, and where a standard Unicode symbol exists, the glyph is at that code point too. Glyphs with no standard symbol are in the Private Use Area.

Ding That GUI

111 glyphs for drawing text interfaces. It’s monospaced and every box-drawing character fills the whole line height, so frames join up with no gaps.

The box-drawing keys are laid out like the shapes they make. q w e, a s d and z x c are the corners, edges and middle of a single-line box, r is a horizontal line and f a vertical one. Hold Shift for double lines. t to m give mixed single and double lines, and i o k l are rounded corners.

Ding That Shapes

94 glyphs. Lowercase letters are solid shapes, uppercase letters are outlines and status symbols, and the heavy arrows follow the number pad: 8 up, 2 down, 4 left, 6 right, and 7 9 1 3 for the diagonals.

Ding That Objects

62 glyphs. Most keys start with the same letter as the object: h house, c car, b bus, t train, e envelope, C calendar.

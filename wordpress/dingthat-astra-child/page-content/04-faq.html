Quick answers about the Ding That fonts. For step-by-step instructions, see Help.

Are the fonts free?

Yes. Download and use them for free, with no account and no fee.

Can I use them in commercial work?

Yes. You can use them in logos, products, apps, games, printed material and websites, for clients and for yourself.

Can I sell them?

Not on their own. The SIL Open Font License lets you bundle the fonts with software you sell, but not sell the fonts by themselves.

Can I change them?

Yes. You can change the glyphs or add new ones. If you share your changed version, it must use the same licence. See Open source and licences.

Do I need to credit Ding That?

No credit is needed in your documents or designs. If you share the font files themselves, include the licence file that comes with them.

Which file should I install?

The .otf file for desktop apps. Use the .ttf only if an app doesn’t accept OpenType. Use the .woff2 on websites.

Why do I see letters instead of pictures?

The text isn’t set in a Ding That font. Select it and choose Ding That GUI, Shapes or Objects from the font menu.

Can I use them in Google Docs?

Not as a font, because Google Docs only offers its own fonts. Insert the SVG file for each glyph as an image instead.

Can glyphs have more than one colour?

No. Each glyph is one shape, in the colour of the text. Change the text colour to recolour it.

Are the fonts accessible?

Screen readers read the key, not the picture, so hide decorative glyphs and label meaningful ones. See how.

Can I suggest a new glyph?

Yes, please. Open an issue on GitHub and describe what you need.

Using what you’ve made

  • To use your text in a document, copy it from the box, paste it, and set it in the same Ding That font.
  • For the box-drawing samples, keep the line spacing at single, or exactly 1.0, so the lines join up.
  • Ready to use the fonts? Download them, then follow the installation help.

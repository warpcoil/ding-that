Ding That is open source. You can read how every glyph is drawn, build the fonts yourself, and suggest changes.

View the source on GitHub

Licence

The fonts are released under the SIL Open Font License 1.1. In short:

  • You can use the fonts for free, in personal and commercial work.
  • You can embed them in documents, apps and websites, and bundle them with software, including software you sell.
  • You can change them and share your changes, under the same licence.
  • You can’t sell the fonts on their own.
  • When you share the font files, include the licence file.

The full text is in OFL.txt in the download and in the repository.

How it’s built

  • Each glyph is drawn in Python from simple shapes (rectangles, circles, polygons and arcs) joined with boolean operations.
  • fontTools compiles the outlines into OTF, TTF and WOFF2 files, and skia-pathops does the boolean operations.
  • Every font file is checked with the OpenType Sanitizer, the same checker web browsers use.

Build it yourself

You need Python 3. In the repository’s source folder, run:

pip install fonttools skia-pathops brotli pillow
python3 package.py

The fonts, SVG files and specimens are written to the dist folder.

Contributing

New glyphs, fixes and ideas are welcome. Open an issue to discuss an idea, or send a pull request.

This site uses WordPress with the Astra theme and a Ding That child theme. The theme’s text fonts are Atkinson Hyperlegible Next and JetBrains Mono, both under the SIL Open Font License 1.1, and it uses the three Ding That fonts for the glyph pictures.
